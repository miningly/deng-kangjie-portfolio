# Deng Kangjie Portfolio

A responsive static portfolio site for product experience and visual system case studies.

## Contents

- `index.html` - Personal homepage with the selected works directory, profile, design directions, and contact section.
- `movie.html` - Movie Box product experience case study.
- `icons.html` - Future Home Icons visual system case study.
- `styles.css` - Responsive visual system and layout styles.
- `projects.js` - Data for the homepage work directory.
- `script.js` - Mobile navigation, project directory, scroll reveals, and image lightbox behavior.
- `assets/` - Project imagery, including optimized WebP assets for the movie case study.

The site is buildless and can be previewed by opening `index.html` in a browser or serving the folder with a static HTTP server.

## Add a project

1. Create a standalone project HTML page that reuses `styles.css` and `script.js`.
2. Add project assets under `assets/` and provide meaningful alt text.
3. Add the project data to the `portfolioProjects` array in `projects.js`.
4. Keep the homepage directory and project-page quick directory limited to the current project set.
